# 🧊 立方体チャレンジ / Cube Challenge

1つの面から、立方体の残りを予測して描くパース練習ゲームです。

[ブラウザで遊ぶ](https://pigma005-dot.github.io/cube-challenge/) · [itch.io・コメント](https://daromeon.itch.io/cube)

v1.28 / b20261030.8 / 採点世代 g4

## 遊び方

- **ノーマル**：練習2問＋本番6問。本番は1問30秒。ガイド練習は設定でスキップできます。
- **きょうのチャレンジ**：全員共通のお題。日本時間0時更新、1日3回まで。成績を見てから任意でランキングに掲載できます。
- **おまけモード**：時間無制限の練習、変化球の練習、最大26ラウンドの無限モード。

ゲーム開始前のアカウント登録は不要。掲載名は空欄でも自動で用意します。ランキングは今日のチャレンジだけが対象です。
名前・得点・入力方法が公開されます。描画データは今回の簡易ランキングには送信しません。
100点の自動掲載除外、短時間の同名・同点数の重複抑制などを行いますが、サーバー再採点や不正の完全排除はしていません。

## 操作

- ペン・マウス・指で描画。Xでペンと消しゴムを切替。
- Space＋ドラッグで移動。ホイールでズーム。タッチは2本指で移動・ズーム。
- Ctrl＋Z / ⌘＋Zで戻す。描画中のEnterで判定。

立方体は1辺1m。固定画角・主点中央のカメラで出題します。
